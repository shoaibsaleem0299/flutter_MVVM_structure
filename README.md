# Hotworx UHF

Flutter (Android + iOS). Feature-first MVVM, Riverpod, go_router, Dio.

## Setup
```bash
flutter pub get
flutter gen-l10n
flutter run --dart-define=API_BASE_URL=https://api.example.com
```

## Commands
```bash
flutter analyze
flutter test
flutter test integration_test
```
